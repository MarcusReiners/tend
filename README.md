# Tend

Ein privates Tagebuch mit optionaler KI-Begleitung. Läuft komplett im Browser als installierbare Web-App.

- Einträge bleiben verschlüsselt auf dem Gerät (AES-256, Schlüssel aus der Passphrase). Es gibt keinen Server und keine Konten.
- Die KI ist optional und sendet nur Einträge, die freigegeben wurden, an den selbst gewählten Anbieter.
- Tend ist kein Ersatz für Therapie oder Notfallhilfe.

Status: privater Prototyp, noch nicht für die allgemeine Nutzung geprüft.
